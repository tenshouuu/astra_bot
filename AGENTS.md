# Agent entrypoint

Read this file first. The canonical rules, roles, and skills are under `ai/`. Rule and skill indexes
in this file are generated and must not be edited manually.

## Loading order

1. Read [AGENT_CONTEXT.md](AGENT_CONTEXT.md) for product scope and current implementation state.
2. Apply every always-on rule listed below.
3. Load scoped rules whose globs cover the files being changed.
4. Load a matching skill and the role it names before doing specialized work.
5. Put plans, investigations, review notes, and other disposable artifacts only in `ai/dev/`.

Run `pnpm sync:agents` after changing canonical rules or skills. Run `pnpm check` before handing
off code when the environment permits it.
